BONELAB MOD HUB — STARTER ZIP
==============================

Files
-----
index.html   Main website
style.css    Dark industrial styling with yellow accents
script.js    Small accessibility/security enhancement

Preview locally
---------------
Open index.html in a web browser.

Publish with GitHub Pages
-------------------------
1. Upload all files to the root of your GitHub repository.
2. Open the repository's Settings > Pages.
3. Under Build and deployment, choose "Deploy from a branch".
4. Select branch "main" and folder "/ (root)", then Save.

Important asset note
--------------------
This ZIP is a working starter site, not the fully branded final version.
It does NOT yet contain official BONELAB, Shizuku, LemonLoader, Fusion,
mod.io, Thunderstore, BoneLib, or CX File Explorer logo/image files.
Neutral letter marks are used instead of presenting generic graphics as
official logos. Add genuine project assets once their exact official files
have been sourced and checked.

This is an unofficial community website and is not affiliated with or
endorsed by Stress Level Zero.
